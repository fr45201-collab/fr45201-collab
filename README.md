## 🚀 Featured Projects (In Development)

> *These projects represent my learning through building. They explore fundamental concepts and are not production systems.*

### **PixelCore3D — Software 3D Renderer**

A CPU-based 3D renderer built from scratch in **C/C++** to understand computer graphics fundamentals.

**Focus Areas:**
- Software rasterization
- Z-buffering and depth testing
- Texture mapping
- 3D transformations and matrices
- Mathematical foundations of rendering

**Repository:** In Development

---

### **TensorX — Deep Learning Framework**

An experimental deep learning framework in **C++** exploring how neural network infrastructure works underneath high-level libraries.

**Focus Areas:**
- Tensor abstractions
- Computational graphs
- Automatic differentiation
- Layer implementations
- Training loops and optimizers

**Repository:** In Development

---

### **NeuraChat — Conversational AI Pipeline**

A **Python + FastAPI** project focused on understanding the complete data-to-model pipeline behind chatbot systems.

**Focus Areas:**
- Dataset engineering and cleaning
- Conversational data processing
- API design for AI applications
- Model integration

**Repository:** In Development
